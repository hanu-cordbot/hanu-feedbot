# HANU-cordbot Feed Tracker

Automated RSS feed monitoring system with web dashboard for Discord communities.

## Live Dashboard
- **Public Tracker**: https://hanu-cordbot.github.io/hanu-feedbot/
- **Admin Dashboard**: https://hanu-cordbot.github.io/hanu-feedbot/dashboard.html

## Features
- Hourly automated feed scanning
- Discord channel integration
- Real-time web dashboard
- Instant feed additions sync directly to the dashboard without waiting for a rebuild
- Mobile-responsive design
- Admin management interface
- Automatic forum post attribution with a subtle link back to the public dashboard
